DotNet.MTPTestOptions Type

Namespace: Fake.DotNet
Assembly: Fake.DotNet.Cli.dll
Parent Module: DotNet
Base Type: obj
All Interfaces: IEquatable<MTPTestOptions> , IStructuralEquatable , IComparable<MTPTestOptions> , IComparable , IStructuralComparable

dotnet test command options for the Microsoft.Testing.Platform runner, see DotNet.testMTP. With that runner dotnet test understands only a part of the options itself and passes the others to the test applications. Every test application understands the options of the platform. An option of a test framework or of an extension is rejected as an invalid command line by a test application that does not reference that framework or extension, and the test run fails; the documentation of each such field names what is needed.
